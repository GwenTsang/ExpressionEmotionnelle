# Piste future 12 : documenter les emotions multiples

- Objectif : documenter clairement le passage de `emotion1`, `emotion2`, `emotion3` vers des observations emotionnelles d'analyse.
- Statut : piste future de documentation methodologique.

Principe probable :

```text
une unite textuelle annotee avec plusieurs emotions
-> une observation par emotion conservee pour l'analyse
```

Pour Glozz, `Categorie` et `Categorie2` peuvent contribuer a deux observations emotionnelles distinctes. Pour XLSX, les emotions issues d'un meme span peuvent aussi contribuer a plusieurs observations.

Point a expliciter :

- une meme unite textuelle peut contribuer plusieurs fois a l'analyse emotionnelle ;
- ce comptage se fait une fois par emotion annotee ;
- cette strategie est plus comparable qu'une analyse fondee uniquement sur `categorie1`.
